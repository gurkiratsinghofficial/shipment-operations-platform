# Shipment Operations & Document Verification Platform

A React-based application for managing shipment records and reviewing shipment details alongside supporting documents. It combines shipment search and organization with document-assisted data entry, where selected OCR text can be used to populate form fields.

## Tech Stack

- **React 19** – UI and component architecture
- **JavaScript (ES6+)** – Application logic
- **React Router** – Client-side routing
- **Webpack 5** – Bundling and development server
- **Babel** – JavaScript and JSX transformation
- **Tailwind CSS 3** – Styling and responsive layouts
- **PostCSS & Autoprefixer** – CSS processing
- **Lucide React** – Icons
- **Web Workers** – Background data processing
- **Jest & React Testing Library** – Testing

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm

### Install dependencies

```bash
git clone https://github.com/gurkiratsinghofficial/shipment-operations-platform.git
cd shipment-operations-platform
npm install
```

### Run locally

```bash
npm start
```

### Create a production build

```bash
npm run build
```

The production build is generated in the configured Webpack output directory.
